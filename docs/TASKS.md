# Tasks for Student Management System

- **JAVA-01**: Create `Student` Entity with fields (id, firstName, lastName, email, dateOfBirth). Use JPA annotations.
- **JAVA-02**: Create `StudentRepository` interface extending `JpaRepository`.
- **JAVA-03**: Create `StudentService` interface and its implementation to save a new student.
- **JAVA-04**: Implement GET all students API in the service layer.
- **JAVA-05**: Implement GET student by ID in the service layer, throwing a custom `ResourceNotFoundException` if not found.
- **JAVA-06**: Implement UPDATE student details.
- **JAVA-07**: Implement DELETE student by ID.
- **JAVA-08**: Create `StudentController` and wire up the REST endpoints (POST, GET, PUT, DELETE) mapping to the service layer.
- **JAVA-09**: Add Jakarta Validation annotations to the `Student` entity or DTO (e.g., `@NotBlank`, `@Email`) and enforce them in the controller with `@Valid`.
- **JAVA-10**: Implement a Global Exception Handler (`@ControllerAdvice`) to handle `ResourceNotFoundException` and validation errors gracefully.
- **JAVA-11**: Add a custom repository method `findByEmail(String email)`.
- **JAVA-12**: Add a search API in the controller to search students by email.
- **JAVA-13**: Update the GET all students API to support Pagination and Sorting using `Pageable`.
- **JAVA-14**: Create a `Course` entity (id, title, description, credits).
- **JAVA-15**: Establish a Many-to-Many relationship between `Student` and `Course`.
- **JAVA-16**: Create `CourseRepository`.
- **JAVA-17**: Implement API to enroll a student in a course (`POST /students/{studentId}/courses/{courseId}`).
- **JAVA-18**: Implement API to retrieve all courses for a specific student (`GET /students/{studentId}/courses`).
- **JAVA-19**: Write Unit Tests for `StudentService` using JUnit 5 and Mockito.
- **JAVA-20**: Write Unit Tests for `StudentController` using `@WebMvcTest` and `MockMvc`.
- **JAVA-21**: Write Integration Tests for repository layer using Testcontainers (MySQL).
- **JAVA-22**: Create an `Attendance` Entity (id, date, status) with a Many-to-One relationship to `Student`.
- **JAVA-23**: Implement APIs to mark attendance and retrieve attendance history for a student.
- **JAVA-24**: Add Springdoc OpenAPI (Swagger) dependency and document all REST API endpoints.
