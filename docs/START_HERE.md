## 😭 When your code breaks...

Don't panic. Errors are part of programming. This repository is intentionally designed so that you WILL encounter them while learning.

*   **Compilation error?** → Read the first useful error in the terminal.
*   **Test failure?** → Read the test name (it tells you what it expected).
*   **GitHub Action failed?** → Open the failed check on GitHub and see what went wrong.
*   **Still stuck?** → Read `docs/HINTS.md`.
*   **Still really stuck?** → Look at the corresponding solution in the `rishi-solutions` branch after you've attempted the task.

## 🧭 How To Navigate (Example)
Let's look at an example task: **JAVA-18-service**

**File:**
`backend/src/main/java/com/example/studentmanagement/service/AttendanceService.java`

**Class:**
`AttendanceService`

**Method:**
`getAttendanceSummary(Long studentId, Long subjectId)`

**How to find it:**
1. Open the folder `backend`
2. Open `src` → `main` → `java` → `com` → `example` → `studentmanagement` → `service`
3. Open the file `AttendanceService.java`
4. Scroll down until you find the method `getAttendanceSummary()`
5. Write your code inside that method!
