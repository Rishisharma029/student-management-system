# START HERE — KHUSHI 👋

## Welcome!
Welcome to your personalized Java Backend training environment! 

- The application structure is already built for you.
- **You do NOT need to understand every folder before starting.**
- You will complete one task at a time.
- Every task tells you the **exact file and exact method** to modify.
- GitHub Actions will automatically check your work when you push.

## IMPORTANT RULES
**DO NOT randomly edit files.**

For each task, follow this exact loop:
1. Open `docs/TASKS.md`
2. Find your task ID (e.g., `JAVA-01`)
3. Open the **exact file path** provided
4. Find the **exact method**
5. Read the requirements in the comments
6. Implement it!
7. Run the tests locally (`.\mvnw.cmd clean test`)
8. Commit your work
9. Push to GitHub
10. Check GitHub Actions (Wait for the Green ✅)
11. Move to the next task!

## 📂 Repository Map
Don't be overwhelmed by the files. Here is all you need to know:

* `backend/` → The Java + Spring Boot application (You will work here!).
* `frontend/` → The React user interface (Ignore this for now).
* `database/` → SQL database setup instructions.
* `docs/` → Your instructions, tasks, hints, and learning materials.
* `.github/` → The automated robot that checks your code.

## 🧭 How To Navigate (Example)
Let's look at an example task: **JAVA-18-service**

**File:**
`backend/src/main/java/com/example/studentmanagement/service/AttendanceService.java`

**Class:**
`AttendanceService`

**Method:**
`getAttendanceSummary(Long studentId, Long subjectId)`

**How to find it:**
1. Open the folder `backend`
2. Open `src` → `main` → `java` → `com` → `example` → `studentmanagement` → `service`
3. Open the file `AttendanceService.java`
4. Scroll down until you find the method `getAttendanceSummary()`
5. Write your code inside that method!
