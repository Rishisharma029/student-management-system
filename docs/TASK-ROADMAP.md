# 🗺️ Learning Roadmap

Follow this exact order. **Complete each phase before moving to the next!**

## 🌱 Phase 1 — Get comfortable
*Start with the Student service. You'll learn how the Java code you're already familiar with begins interacting with a real application.*

- **JAVA-01**: `StudentService` -> `createStudent()`
- **JAVA-02**: `StudentService` -> `getAllStudents()`
- **JAVA-03**: `StudentService` -> `getStudentById()`
- **JAVA-04**: `StudentService` -> `updateStudent()`
- **JAVA-05**: `StudentService` -> `deleteStudent()`
- **JAVA-06**: `StudentService` -> `searchStudents()`

## 🔧 Phase 2 — Talk to the database
*Now you'll work with repositories and Spring Data JPA. This is where Java starts doing something useful with actual data.*

- **JAVA-09** to **JAVA-18-repo**: `StudentRepository` methods.

## 📊 Phase 3 — Build real business logic
*Attendance. This is where things become more interesting because you're no longer just storing data — you're making the application actually DO something.*

- **JAVA-17-service**: `AttendanceService` -> `markAttendance()`
- **JAVA-18-service**: `AttendanceService` -> `getAttendanceSummary()`

## 🧪 Phase 4 — Make the application survive mistakes
*Exception handling and validation. Because real applications have users who enter unexpected things. 😭*

- **JAVA-19** to **JAVA-26**: `GlobalExceptionHandler` methods.

## 🧠 Phase 5 — Teach the code to prove itself
*Testing. Your code should be able to prove that it works.*

- **JAVA-27** to **JAVA-35**: `StudentServiceTest` methods.

## 🚀 Phase 6 — Build something independently
*Final challenge. No step-by-step implementation. Just requirements. This is where you'll see how much you've learned.*

- **JAVA-36** to **JAVA-38**: `StudentService` filters.
