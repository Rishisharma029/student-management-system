# Hints

- **JAVA-01**: Don't forget `@Entity`, `@Table`, `@Id`, and `@GeneratedValue(strategy = GenerationType.IDENTITY)`.
- **JAVA-02**: `public interface StudentRepository extends JpaRepository<Student, Long> {}`.
- **JAVA-03**: Use `@Service` on the implementation class and `@Autowired` (or constructor injection) for the repository.
- **JAVA-04**: `repository.findAll()` returns a List.
- **JAVA-05**: Use `repository.findById(id).orElseThrow(...)`.
- **JAVA-06**: Fetch the existing entity, update fields, and save it.
- **JAVA-07**: Use `repository.deleteById(id)`.
- **JAVA-08**: Annotate with `@RestController` and `@RequestMapping("/api/v1/students")`.
- **JAVA-09**: Use `@NotNull`, `@Size` for strings, and `@Past` for dates. Use `@Valid` in method arguments in the controller.
- **JAVA-10**: Look into `@ExceptionHandler(MethodArgumentNotValidException.class)` to format validation errors.
- **JAVA-11**: JPA method naming convention: `Optional<Student> findByEmail(String email);`
- **JAVA-12**: Map to `/api/v1/students/search?email=...` using `@RequestParam`.
- **JAVA-13**: The repository method should accept `PageRequest.of(page, size, Sort.by(direction, property))`.
- **JAVA-14**: Similar to Student entity.
- **JAVA-15**: Use `@ManyToMany` and `@JoinTable` on one side of the relationship.
- **JAVA-16**: Standard `JpaRepository`.
- **JAVA-17**: Fetch both entities, add the course to the student's set of courses, and save the student.
- **JAVA-18**: You can return `student.getCourses()`. Watch out for Lazy Initialization issues!
- **JAVA-19**: Use `@ExtendWith(MockitoExtension.class)`. Mock the repository.
- **JAVA-20**: Use `@MockBean` for the service layer inside `@WebMvcTest`.
- **JAVA-21**: Annotate with `@DataJpaTest` and `@AutoConfigureTestDatabase(replace = Replace.NONE)`.
- **JAVA-22**: Use `@ManyToOne` and `@JoinColumn(name = "student_id")`.
- **JAVA-23**: The path could be `/api/v1/students/{id}/attendance`.
- **JAVA-24**: Add `springdoc-openapi-starter-webmvc-ui` to your `pom.xml`.
